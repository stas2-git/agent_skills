## How To Use

1. Start with the summary that matches the task.
2. Use the "Skill extraction opportunities" section to decide whether the idea belongs in `SKILL.md`, `references/`, `scripts/`, or eval prompts.
3. Load the original whitepaper only when the summary is not enough or exact source detail matters.
4. When shortening skill references, prefer copying or adapting from these summaries instead of using the raw whitepaper text.
